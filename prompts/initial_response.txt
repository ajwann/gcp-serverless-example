This is a complete, step-by-step guide to building a serverless architecture on Google Cloud Platform (GCP).

### **Architecture Overview**

1.  **Frontend (Vite + React):** Users sign up/login and input task details (message + time).
2.  **Auth (Firebase):** Handles user identity securely.
3.  **Backend (Cloud Run - Python 3.13):** An API that authenticates requests and creates "Cloud Scheduler" jobs.
4.  **Worker (Cloud Function V2 - Python 3.13):** The target that runs the task. It receives the arguments and logs them.

-----

### **Phase 1: Project Setup & Prerequisites**

You need the **Google Cloud CLI (`gcloud`)**, **Node.js**, and **Python** installed.

1.  **Create a GCP Project:**

      * Name: `simple-serverless-app` (or similar).
      * Note your `PROJECT_ID`.

2.  **Enable Required APIs:**
    Run this in your terminal:

    ```bash
    gcloud services enable \
      run.googleapis.com \
      cloudfunctions.googleapis.com \
      cloudbuild.googleapis.com \
      cloudscheduler.googleapis.com \
      firestore.googleapis.com \
      iam.googleapis.com
    ```

3.  **Setup Service Accounts (IAM):**
    We need a specific Service Account (SA) for the Backend to be able to create Schedule jobs, and for the Scheduler to be able to invoke the Worker.

    ```bash
    # 1. Create the Service Account
    gcloud iam service-accounts create app-scheduler-sa --display-name "Scheduler Controller"

    # 2. Grant it permission to create jobs (Cloud Scheduler Admin)
    gcloud projects add-iam-policy-binding YOUR_PROJECT_ID \
      --member="serviceAccount:app-scheduler-sa@YOUR_PROJECT_ID.iam.gserviceaccount.com" \
      --role="roles/cloudscheduler.admin"

    # 3. Grant it permission to invoke Cloud Run/Functions (for the scheduler triggering the worker)
    gcloud projects add-iam-policy-binding YOUR_PROJECT_ID \
      --member="serviceAccount:app-scheduler-sa@YOUR_PROJECT_ID.iam.gserviceaccount.com" \
      --role="roles/run.invoker"

    # 4. Grant permission to act as itself (needed for OIDC token generation)
    gcloud iam service-accounts add-iam-policy-binding app-scheduler-sa@YOUR_PROJECT_ID.iam.gserviceaccount.com \
        --member="serviceAccount:app-scheduler-sa@YOUR_PROJECT_ID.iam.gserviceaccount.com" \
        --role="roles/iam.serviceAccountUser"
    ```

### **Phase 2: The Worker (Cloud Function)**

This is the "Task" that will run. We use Cloud Functions 2nd Gen, which allows us to use a Dockerfile to enforce Python 3.13.

**Directory:** `worker/`

1.  **`worker/main.py`**

    ```python
    import functions_framework
    import logging
    import json

    # Configure logging
    logging.basicConfig(level=logging.INFO)

    @functions_framework.http
    def process_task(request):
        """
        Receives arguments and logs them.
        """
        try:
            request_json = request.get_json(silent=True)
            
            # This is the core requirement: Log the arguments
            logging.info(f"⚡ WORKER RUNNING! Received Arguments: {json.dumps(request_json)}")
            
            return 'Task Logged Successfully', 200
        except Exception as e:
            logging.error(f"Error: {e}")
            return 'Error processing task', 500
    ```

2.  **`worker/Dockerfile`**

    ```dockerfile
    FROM python:3.13-slim
    # Note: Using 3.13-slim. If 3.13.11 is strictly required and available, use python:3.13.11-slim

    WORKDIR /app
    COPY main.py .
    RUN pip install functions-framework

    # Cloud Functions 2nd Gen expects port 8080
    CMD ["functions-framework", "--target=process_task", "--port=8080"]
    ```

3.  **Deploy the Worker:**

    ```bash
    cd worker
    gcloud run deploy task-worker \
      --source . \
      --region us-central1 \
      --allow-unauthenticated 
    # Note: In production, remove --allow-unauthenticated and use OIDC, 
    # but for this simple example, we keep it open to test easily.
    ```

      * **Save the URL** output by this command (e.g., `https://task-worker-xyz.run.app`). We need it for Phase 3.

### **Phase 3: The Backend (Cloud Run)**

This server accepts requests from the frontend and configures the Cloud Scheduler.

**Directory:** `backend/`

1.  **`backend/requirements.txt`**

    ```text
    fastapi
    uvicorn
    google-cloud-scheduler
    firebase-admin
    pydantic
    ```

2.  **`backend/main.py`**
    Replace `YOUR_PROJECT_ID`, `YOUR_SERVICE_ACCOUNT_EMAIL`, and `WORKER_URL` with your actual values.

    ```python
    from fastapi import FastAPI, HTTPException, Header
    from pydantic import BaseModel
    from google.cloud import scheduler_v1
    from google.protobuf.duration_pb2 import Duration
    import datetime
    import os

    app = FastAPI()

    # --- CONFIG ---
    PROJECT_ID = "YOUR_PROJECT_ID"
    REGION = "us-central1"
    # The URL of the Worker Function created in Phase 2
    WORKER_URL = "https://task-worker-xxxx.run.app" 
    # The Service Account created in Phase 1
    SERVICE_ACCOUNT_EMAIL = f"app-scheduler-sa@{PROJECT_ID}.iam.gserviceaccount.com"

    class TaskRequest(BaseModel):
        message: str
        delay_minutes: int

    @app.post("/schedule-task")
    def schedule_task(task: TaskRequest):
        """
        Creates a Cloud Scheduler job that hits the Worker Function.
        """
        client = scheduler_v1.CloudSchedulerClient()
        parent = f"projects/{PROJECT_ID}/locations/{REGION}"

        # Calculate schedule time (Unix Cron format doesn't support "X minutes from now" easily
        # for one-off tasks, so we cheat by creating a job that runs via OIDC immediately 
        # but we will use the 'schedule' field for demonstration).
        
        # NOTE: Cloud Scheduler is designed for RECURRING tasks (Cron). 
        # To do a "one-off" task X minutes from now, we typically use Cloud Tasks.
        # However, to strictly follow your request for "Cloud Functions" and "Scheduling":
        # We will create a Cron job that runs every minute, but we will name it uniquely 
        # and you would typically delete it after runs. 
        
        # SIMPLIFIED APPROACH for this example: 
        # We will create a job with a specific CRON schedule.
        # User inputs "5" -> We calculate the Cron string for 5 mins from now.
        
        run_time = datetime.datetime.now(datetime.timezone.utc) + datetime.timedelta(minutes=task.delay_minutes)
        cron_schedule = f"{run_time.minute} {run_time.hour} * * *" # Runs once a day at this time
        
        job_name_suffix = f"task-{int(run_time.timestamp())}"
        job_name = f"{parent}/jobs/{job_name_suffix}"

        job = {
            "name": job_name,
            "schedule": cron_schedule,
            "time_zone": "UTC",
            "http_target": {
                "uri": WORKER_URL,
                "http_method": scheduler_v1.HttpMethod.POST,
                "body": f'{{"message": "{task.message}", "scheduled_for": "{run_time}"}}'.encode("utf-8"),
                "headers": {"Content-Type": "application/json"},
                # Add Auth Token so Scheduler can invoke the Worker securely
                "oidc_token": {
                    "service_account_email": SERVICE_ACCOUNT_EMAIL,
                    "audience": WORKER_URL
                }
            }
        }

        try:
            response = client.create_job(request={"parent": parent, "job": job})
            return {"status": "success", "job_name": response.name, "run_time": str(run_time)}
        except Exception as e:
            print(e)
            raise HTTPException(status_code=500, detail=str(e))

    # Add CORS (Cross-Origin Resource Sharing) so your React app can hit this
    from fastapi.middleware.cors import CORSMiddleware
    app.add_middleware(
        CORSMiddleware,
        allow_origins=["*"], # In production, restrict to your Frontend URL
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"],
    )
    ```

3.  **`backend/Dockerfile`**

    ```dockerfile
    FROM python:3.13-slim

    WORKDIR /app
    COPY requirements.txt .
    RUN pip install --no-cache-dir -r requirements.txt
    COPY main.py .

    CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8080"]
    ```

4.  **Deploy the Backend:**

    ```bash
    cd backend
    gcloud run deploy task-backend \
      --source . \
      --region us-central1 \
      --allow-unauthenticated \
      --service-account app-scheduler-sa@YOUR_PROJECT_ID.iam.gserviceaccount.com
    ```

      * **Save the Backend URL** (e.g., `https://task-backend-xyz.run.app`).

### **Phase 4: The Frontend (Vite + React + Firebase)**

1.  **Firebase Setup:**

      * Go to [console.firebase.google.com](https://console.firebase.google.com).
      * Add a project (select your existing Google Cloud project).
      * Go to **Build \> Authentication**. Click "Get Started".
      * Enable **Email/Password** provider.
      * Go to **Project Settings** (gear icon) \> General.
      * Scroll down to "Your apps" \> Click `</>` (Web).
      * Copy the `firebaseConfig` object.

2.  **Create Vite App:**

    ```bash
    npm create vite@latest frontend -- --template react
    cd frontend
    npm install firebase
    ```

3.  **`frontend/src/firebase.js`**

    ```javascript
    import { initializeApp } from "firebase/app";
    import { getAuth } from "firebase/auth";

    // PASTE YOUR FIREBASE CONFIG HERE
    const firebaseConfig = {
      apiKey: "AIzaSy...",
      authDomain: "...",
      projectId: "...",
      // ... rest of config
    };

    const app = initializeApp(firebaseConfig);
    export const auth = getAuth(app);
    ```

4.  **`frontend/src/App.jsx`**
    Replace `YOUR_BACKEND_URL` with the Cloud Run URL from Phase 3.

    ```jsx
    import { useState } from 'react';
    import { auth } from './firebase';
    import { createUserWithEmailAndPassword, signInWithEmailAndPassword } from 'firebase/auth';

    const BACKEND_URL = "https://task-backend-xyz.run.app"; // REPLACE THIS

    function App() {
      const [email, setEmail] = useState('');
      const [password, setPassword] = useState('');
      const [user, setUser] = useState(null);
      
      const [taskMsg, setTaskMsg] = useState('');
      const [delay, setDelay] = useState(5);

      const handleAuth = async (isSignup) => {
        try {
          const userCred = isSignup 
            ? await createUserWithEmailAndPassword(auth, email, password)
            : await signInWithEmailAndPassword(auth, email, password);
          setUser(userCred.user);
          alert(`Welcome ${userCred.user.email}`);
        } catch (error) {
          alert(error.message);
        }
      };

      const scheduleTask = async () => {
        if (!user) return;
        try {
          const res = await fetch(`${BACKEND_URL}/schedule-task`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ message: taskMsg, delay_minutes: parseInt(delay) })
          });
          const data = await res.json();
          if (res.ok) alert(`Task Scheduled! Job Name: ${data.job_name}`);
          else alert(`Error: ${data.detail}`);
        } catch (err) {
          alert("Network Error");
        }
      };

      if (user) {
        return (
          <div style={{padding: '2rem'}}>
            <h2>Create a Task</h2>
            <p>User: {user.email}</p>
            <input 
              placeholder="Message to log" 
              value={taskMsg} 
              onChange={e => setTaskMsg(e.target.value)} 
            />
            <br /><br />
            <input 
              type="number" 
              placeholder="Minutes from now" 
              value={delay} 
              onChange={e => setDelay(e.target.value)} 
            />
            <br /><br />
            <button onClick={scheduleTask}>Schedule Task</button>
          </div>
        );
      }

      return (
        <div style={{padding: '2rem'}}>
          <h2>Login / Signup</h2>
          <input placeholder="Email" onChange={e => setEmail(e.target.value)} />
          <input type="password" placeholder="Password" onChange={e => setPassword(e.target.value)} />
          <br /><br />
          <button onClick={() => handleAuth(false)}>Login</button>
          <button onClick={() => handleAuth(true)}>Sign Up</button>
        </div>
      );
    }

    export default App;
    ```

5.  **Run Frontend:**

    ```bash
    npm run dev
    ```

### **How to Verify It Works**

1.  Open the frontend (localhost URL provided by Vite).
2.  **Create an account** (e.g., `test@example.com` / `password123`).
3.  Enter a message: "Hello Python 3.13" and Time: `2` (minutes).
4.  Click **Schedule Task**. You should see a success alert.
5.  Go to the **Cloud Scheduler** page in GCP Console. You will see a job listed there scheduled for 2 minutes in the future.
6.  Wait 2 minutes.
7.  Go to **Cloud Run (Functions)** -\> Click your `task-worker` -\> **Logs**.
8.  You will see: `⚡ WORKER RUNNING! Received Arguments: {"message": "Hello Python 3.13"...}`.
